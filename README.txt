Files:

- KARJAT_PARTY_QUEST_QR_CODES.pdf — printable QR cards

On iPad:
1. Download and extract this ZIP in Files.
2. Open https://github.com/heymilan/treasure-hunt-index in Safari.
3. Replace the existing index.html: open the file in the repo, use Edit (pencil) if offered, or Add file > Upload files with the new index.html and commit the change.
4. Upload admin.html to the repository root and commit.
5. Wait a few minutes. Player page: https://heymilan.github.io/treasure-hunt-index/
6. Host page: https://heymilan.github.io/treasure-hunt-index/admin.html
7. Keep admin URL private. It is unlisted, not password protected.

Game mechanics:
- 5 questions in rounds 1,2,3,5; pass at 3/5.
- Team-specific questions of similar difficulty.
- Unlimited hints; one lifeline per team per quiz round removes two incorrect choices.
- If below 3/5, perform a funny rescue task. Host can award up to 3 rescue points and hand over next QR.
- Round 4: funny performance, host awards up to 5 points.
- Alternate team turns round-by-round.
- Scores are recorded manually by host; no backend score storage.
