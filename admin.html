How to run it

  1. Alternate turns by round: Red Round 1, Blue Round 1, Red Round 2, Blue Round 2, and so on.
  2. Each quiz round has 5 questions. Pass mark is 3/5.
  3. Each team may use one lifeline per round to remove two wrong choices. Hints are unlimited.
  4. If a team scores 0–2, ask them to perform the rescue task. Award up to 3 rescue points, then hand over the next round QR card so the game keeps moving.
  5. Round 4 is a performance challenge. Score up to 5 points using creativity (2), teamwork (2), commitment (1). Each team receives a different task.
  6. Record the scores below. The page does not sync scores between devices.
