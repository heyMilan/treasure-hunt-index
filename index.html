🛟 House rules

  • Walk, don't run. Keep all clues away from wet tiles and the pool edge.
  • No climbing, reaching into machinery, moving heavy furniture or opening private cupboards.
  • Every challenge can be done seated. Acting, singing and personal sharing are optional; a teammate can narrate instead.
  • Ask the host for a hint if you're stuck. Fun beats frustration.
