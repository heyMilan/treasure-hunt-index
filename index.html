How it works

  • Quiz rounds contain 5 multiple-choice questions. Pass with 3 out of 5 correct.
  • Each question has one hint. Use one team lifeline per round to eliminate two wrong options; it doesn't cost a point.
  • If you score below 3, try the funny rescue task. Perform it for the host, then the host may hand over the next round's QR card.
  • Host awards up to 5 points for funny tasks. Quiz points and task points count toward the final winner.
Safety: no running, climbing, pool-edge antics or searching in private rooms. Every task can be done seated.
